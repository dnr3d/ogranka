# Огранка

Прототип мобильной игры для браузера: кампус с персонажами и забеги по кабинетам с мини-играми. Без сборки и зависимостей: достаточно открыть `index.html` через любой статический сервер.

Мини-игра три в ряд лежит в `js/match3.js`, кампус и забег в `js/meta.js`. Имена, тексты и заштрихованный арт пока заглушки.

**Играть:** https://dnr3d.github.io/ogranka/

## Правила

Меняйте соседних зверей свайпом или двумя тапами и собирайте нужных за ограниченное число ходов.

- 4 в ряд: крест, бьёт по ряду и столбцу.
- Уголок: взрыв вокруг.
- 5 в ряд: звезда, убирает всех зверей одного вида.

## Ассеты

Поле и звери лежат в папке `assets`. Бонусы пока нарисованы кодом в `drawPiece`.
