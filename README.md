# Огранка

Прототип мобильной игры «три в ряд» для браузера. Без сборки и зависимостей: достаточно открыть `index.html` через любой статический сервер.

**Играть:** https://dnr3d.github.io/ogranka/

## Правила

Меняйте соседних зверей свайпом или двумя тапами и собирайте нужных за ограниченное число ходов.

- 4 в ряд: крест, бьёт по ряду и столбцу.
- Уголок: взрыв вокруг.
- 5 в ряд: звезда, убирает всех зверей одного вида.

## Ассеты

Поле и звери лежат в папке `assets`. Бонусы пока нарисованы кодом в `drawPiece`.
