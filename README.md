# Огранка

Прототип мобильной игры «три в ряд» для браузера. Без сборки и зависимостей: достаточно открыть `index.html` через любой статический сервер.

**Играть:** https://dnr3d.github.io/ogranka/

## Правила

Меняйте соседние камни свайпом или двумя тапами и собирайте нужные камни за ограниченное число ходов.

- 4 в ряд: дуга, бьёт по ряду и столбцу.
- Уголок: сердце-бомба, взрывает камни вокруг.
- 5 в ряд: звезда, убирает все камни одного цвета.
